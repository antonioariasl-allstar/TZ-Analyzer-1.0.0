Qué hacer en casa (paso a paso)
1) Obtener código y ramas actualizadas
   PowerShell (Windows):
   
   git fetch --all --prune
   git switch main
   git pull
   
   Nota: Solo cambia a la rama feature/gui-customtkinter-wizard cuando vayamos a empezar el GUI. Por ahora, las pruebas/manuales van sobre main.

2) Asegurar el entorno Python 3.12.8
   - Verifica versión:
     
     python --version
     
   - Si no es 3.12.8, instala Python 3.12.8 y crea un venv local en la carpeta del repo:
     
     python -m venv .venv312
     .\.venv312\Scripts\Activate.ps1
     python --version  # debe mostrar 3.12.8
     
   - Instala dependencias:
     
     pip install --upgrade pip
     pip install -r requirements.txt

3) Prueba rápida de regresión (opcional pero recomendable)
   - Ejecuta el test de regresión para validar generación KMZ:
     
     python .\tests\test_kml_regresion.py

4) Pruebas manuales del programa (menú principal)
   - Ejecuta el entrypoint:
     
     python run.py
     
   - Recorre los flujos del menú (opciones 1, 2 y 3) con archivos de ejemplo. Anota cualquier error o comportamiento inesperado.

5) Documenta lo realizado en casa
   - Actualiza TODO.md con una sección "Sesión en casa - YYYY-MM-DD" resumiendo:
     - Qué opciones del menú probaste y resultados.
     - Cualquier problema encontrado (con mensajes completos de error, si aplica).
     - Decisiones o cambios pendientes.
   - Alternativamente, crea un archivo nuevo del estilo `BITACORA_CASA_YYYYMMDD.txt` en la raíz del repo con el mismo contenido.
   - Haz commit/push de esa documentación para que en la oficina podamos sincronizarnos fácilmente.

6) Siguiente hito (cuando las pruebas manuales estén OK)
   - Preparar empaquetado con PyInstaller (pendiente de ejecutar después de validar):
     - Incluir `config.json` como dato junto al ejecutable.
     - Objetivo: ejecutable onefile y sin consola.
     - Ejemplo de comando (ajustar rutas si es necesario):
       
       pyinstaller --noconsole --onefile --name "TZ-Analysis" --add-data "config.json;." run.py
       
     - Probar el binario resultante en una máquina limpia.
